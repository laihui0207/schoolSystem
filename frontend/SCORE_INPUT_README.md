## 🔌 后端接口要求

确保后端已实现以下接口:

1. **GET** `/scores/class-list`
   - 参数: `examId`, `classId`, `subjectId`
   - 返回: 班级学生成绩列表

2. **POST** `/scores/input`
   - Body: 单个成绩数据
   - 功能: 录入/更新成绩

3. **GET** `/scores/statistics`
   - 参数: `examId`, `classId`, `subjectId`
   - 返回: 统计信息（录入进度、平均分等）

4. **POST** `/scores/import`
   - Body: FormData (file, examId, classId, subjectId)
   - 功能: Excel批量导入

5. **GET** `/scores/template`
   - 返回: Excel模板文件 (Blob)
