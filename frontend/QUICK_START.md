# 🚀 成绩录入功能 - 快速开始

## 📝 5分钟上手指南

### 步骤 1: 启动项目

```bash
# 进入前端目录
cd frontend

# 启动开发服务器
npm run dev
```

浏览器访问: `http://localhost:3000`

---

### 步骤 2: 进入成绩录入

1. 登录系统
2. 点击左侧菜单 **"成绩管理"**
3. 点击 **"成绩录入"** 卡片

---

### 步骤 3: 选择录入对象

在成绩录入选择页:

1. **选择考试** - 下拉框中选择"录入中"状态的考试
2. **选择班级** - 自动加载该考试关联年级的班级
3. **选择科目** - 选择要录入成绩的科目
4. **查看进度** - 显示当前班级该科目的录入进度

---

### 步骤 4: 开始录入成绩

点击 **"开始录入"** 按钮，进入成绩录入表格页。

#### 方式1: 单个录入（推荐）

1. 在分数输入框中输入成绩
2. 按 `Tab` 键或点击其他地方
3. 自动保存 ✅

#### 方式2: 批量录入

1. 连续输入多个学生的成绩
2. 点击 **"批量保存"** 按钮
3. 一次性保存所有修改 ✅

#### 方式3: Excel导入

1. 点击 **"导入Excel"** 按钮
2. 上传填好的Excel文件
3. 查看预览和校验结果
4. 点击 **"确认导入"** ✅

---

### 步骤 5: 特殊操作

#### 标记缺考学生

- 勾选 **"缺考"** 复选框
- 分数自动设为 0 且禁用
- 自动保存

#### 添加备注

- 在 **"备注"** 列输入说明
- 失焦自动保存

---

### 步骤 6: 查看统计

录入过程中，顶部统计区域实时显示:

- 📊 **录入进度**: 已录入 / 总人数
- 📈 **平均分**: 当前平均分
- 🏆 **最高分 / 最低分**
- ✅ **及格率**: 百分比

---

## 💡 使用技巧

### 键盘快捷键

- `Tab` - 切换到下一个输入框
- `Enter` - 保存当前行
- `Shift + Tab` - 切换到上一个输入框

### 自动保存

系统会在以下情况自动保存:

- ⏱️ 每隔 5 秒自动保存未保存的数据
- 👆 输入框失焦时立即保存
- ✅ 勾选/取消缺考时立即保存

### 进度指示

- 右上角显示最后保存时间
- 自动保存时显示旋转图标 🔄
- 保存按钮显示 Loading 状态

## 📥 Excel导入步骤

### 1. 下载模板

在成绩录入选择页，点击 **"下载模板"** 按钮。

### 2. 填写Excel

模板格式:

| 学号 | 姓名 | 分数 | 缺考 | 备注 |
|------|------|------|------|------|
| 2021001 | 张三 | 85 | 否 | - |
| 2021002 | 李四 | 92 | 否 | - |
| 2021003 | 王五 | 0 | 是 | 请假 |

**注意事项**:
- 学号、姓名必填
- 分数范围: 0-满分
- 缺考填"是"或"否"（或 1/0）
- 缺考学生分数填 0

### 3. 上传导入

1. 点击 **"导入Excel"** 按钮
2. 拖拽或点击上传文件
3. 点击 **"解析数据"**
4. 查看预览和校验结果
5. 确认无误后点击 **"确认导入"**

### 4. 查看结果

- ✅ 绿色标签: 有效数据
- ❌ 红色标签: 错误数据（需修正）
- 错误列表显示具体原因

## ⚠️ 常见问题

### Q1: 选不到考试怎么办？

**A**: 只能选择"录入中"状态的考试。请先在考试管理中将考试设为"录入中"状态。

### Q2: 数据没有自动保存？

**A**: 
- 检查网络连接
- 查看右上角是否有错误提示
- 手动点击"保存"按钮

### Q3: Excel导入失败？

**A**: 检查以下内容:
- 文件格式是否为 .xlsx 或 .xls
- 文件大小是否超过 5MB
- 表头是否与模板一致
- 数据格式是否正确

### Q4: 统计信息不更新？

**A**: 
- 点击"刷新数据"按钮
- 确认数据已成功保存
- 检查后端接口是否正常

### Q5: 如何修改已录入的成绩？

**A**: 直接在表格中修改即可，失焦或点击保存按钮后自动更新。

## 🎯 最佳实践

### 推荐流程

1. **准备阶段**
   - 确认考试已创建并设为"录入中"
   - 确认学生已分配到相应班级
   - 准备好纸质成绩单

2. **录入阶段**
   - 小班级(<30人): 直接在线录入
   - 大班级(≥30人): 使用Excel导入
   - 先录入正常学生，再标记缺考

3. **检查阶段**
   - 查看统计信息是否合理
   - 检查录入进度是否100%
   - 核对几个学生的成绩

4. **完成阶段**
   - 确认所有数据已保存
   - 通知管理员进行审核

### 提高效率

- ✅ 使用Excel导入（大批量）
- ✅ 利用Tab键快速切换
- ✅ 让系统自动保存
- ✅ 多人协作录入不同科目
