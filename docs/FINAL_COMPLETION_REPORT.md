## 🎨 核心算法实现

### 1. 排名计算算法
```java
// 班级排名
按班级分组 → 按分数降序 → 处理并列 → 更新排名

// 年级排名
按学校分组 → 计算总分 → 排序 → 更新排名

// 校级排名  
汇总所有成绩 → 计算总分 → 全局排序 → 更新排名

// 并列处理
if (当前分数 == 上一个分数) {
    rank = 上一个排名;  // 相同分数，相同排名
} else {
    rank = 实际位置;     // 不同分数，新排名
}
```

### 2. 统计分析算法
```java
// 分数段分布
0-60, 60-70, 70-80, 80-90, 90-100

// 及格率
passRate = (及格人数 / 总人数) × 100%

// 优秀率
excellentRate = (优秀人数 / 总人数) × 100%
```

## 🔄 完整业务流程示例

### 场景：2026年春季期中考试

```bash
# 1. 基础数据准备
POST /api/schools          # 创建学校
POST /api/terms            # 创建学期
POST /api/grades           # 创建年级
POST /api/classes          # 创建班级
POST /api/subjects         # 创建科目

# 2. 人员管理
POST /api/students         # 录入学生
POST /api/students/{id}/assign-class  # 学生分班
POST /api/teachers         # 录入教师

# 3. 考试管理
POST /api/exams            # 创建考试
POST /api/exams/{id}/start-input  # 开始录入

# 4. 成绩录入
POST /api/scores/batch-input  # 批量录入
或
GET  /api/export/score-template  # 下载模板
POST /api/export/import-scores   # Excel导入

# 5. 成绩审核
POST /api/scores/review    # 审核成绩
POST /api/exams/{id}/submit-review  # 提交考试审核
POST /api/exams/{id}/publish  # 发布成绩

# 6. 排名计算
POST /api/scores/calculate-rankings  # 计算排名

# 7. 统计分析
GET /api/stats/personal    # 个人统计
GET /api/stats/class       # 班级统计

# 8. 导出报表
GET /api/export/scores     # 导出Excel

# 9. 通知推送
自动触发成绩发布通知
```
