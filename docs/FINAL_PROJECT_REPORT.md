## 🎨 核心算法实现

### 1. 排名计算算法 ✅
```java
// 班级排名
按班级分组 → 按分数降序 → 处理并列 → 更新排名

// 年级排名
按学校分组 → 计算总分 → 排序 → 更新排名

// 校级排名
汇总所有成绩 → 计算总分 → 全局排序 → 更新排名

// 并列处理
if (当前分数 == 上一个分数) {
    rank = 上一个排名;  // 相同分数，相同排名
} else {
    rank = 实际位置;    // 不同分数，新排名
}
```

### 2. 统计分析算法 ✅
```java
// 分数段分布
0-60, 60-70, 70-80, 80-90, 90-100

// 及格率 = (及格人数 / 总人数) × 100%
// 优秀率 = (优秀人数 / 总人数) × 100%

// 成绩趋势
按考试时间排序 → 计算各次总分/平均分 → 生成趋势数据

// 雷达图数据
各科目得分率 = (实际得分 / 满分) × 100%
```

### 3. 预警机制 ✅
```java
// 不及格预警
if (成绩 < 60分) {
    发送预警通知
}

// 成绩下降预警（待完善）
if (本次成绩 - 上次成绩 < -20分) {
    发送预警通知
}
```
