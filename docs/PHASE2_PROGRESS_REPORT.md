## 📈 核心数据模型

### 1. Exam（考试表）
```java
- id: 主键
- school_id: 学校ID
- term_id: 学期ID
- exam_name: 考试名称
- exam_type: 考试类型（1-5）
- exam_date: 考试日期
- grade_ids: 参与年级（逗号分隔）
- status: 状态（0-3）
```

### 2. ExamSubject（考试科目关联表）
```java
- id: 主键
- exam_id: 考试ID
- subject_id: 科目ID
- full_score: 满分
- sort_order: 排序
```

### 3. Score（成绩表）
```java
- id: 主键
- exam_id: 考试ID
- student_id: 学生ID
- subject_id: 科目ID
- class_id: 班级ID
- school_id: 学校ID
- score: 得分
- is_absent: 是否缺考
- rank_in_class: 班级排名
- rank_in_grade: 年级排名
- rank_in_school: 校级排名
- recorder_id: 录入人
- status: 状态（0-2）
- recorded_at: 录入时间
- reviewed_at: 审核时间
```

## 🔄 业务流程

### 考试成绩管理完整流程

```
1. 创建考试
   ↓
2. 设置考试科目和满分
   ↓
3. 开始成绩录入（状态变为"录入中"）
   ↓
4. 教师录入学生成绩（单个/批量）
   ↓
5. 成绩进入"待审核"状态
   ↓
6. 教研组长审核成绩（通过/驳回）
   ↓
7. 审核通过后，提交整个考试审核（状态变为"审核中"）
   ↓
8. 校领导发布成绩（状态变为"已发布"）
   ↓
9. 计算各级排名
   ↓
10. 学生和家长可查看成绩
```
