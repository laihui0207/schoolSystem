## 🔄 完整业务流程

```
1. 系统初始化
   └─ 配置系统参数 → 设置字典数据
   
2. 基础数据准备
   └─ 创建学校 → 设置学期 → 创建年级 → 创建班级 → 添加科目
   
3. 人员管理
   └─ 录入学生 → 分配班级 → 录入教师 → 设置任教科目
   
4. 考试管理
   └─ 创建考试 → 关联科目 → 设置参与年级 → 开始录入
   
5. 成绩录入
   └─ 手动录入 OR Excel批量导入
   
6. 成绩审核
   └─ 教师审核成绩 → 提交考试审核 → 发布成绩
   
7. 自动处理
   └─ 计算排名 → 检查预警 → 发送通知
   
8. 成绩变更（可选）
   └─ 申请修改 → 审批 → 自动更新 → 记录日志
   
9. 统计分析
   └─ 个人统计 → 班级统计 → 年级对比 → 趋势分析 → 导出报表
   
10. 查看结果
    └─ 学生查看成绩 → 接收通知 → 查看统计报表
```
