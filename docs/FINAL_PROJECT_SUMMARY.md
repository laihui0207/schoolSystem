## 📊 项目概览

## 🚀 快速启动

### 后端启动
```bash
# 启动Docker服务
cd docker && docker-compose up -d

# 编译项目
mvn clean compile -DskipTests

# 启动应用
mvn spring-boot:run -DskipTests

# 访问地址
http://localhost:8080
```

### 前端启动
```bash
# 安装依赖
cd frontend && npm install

# 启动开发服务器
npm run dev

# 访问地址
http://localhost:3000
```
